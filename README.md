# Kermesite Cipher

Full-colour Python 3 neon glyph-stamp arcade for ElbowOS.

Glyphs rise in five lanes. Slide the sulfur seal and stamp the next letter of the word plate (FLARE, EMBER, VEIN, GLOW, SPARK, ORE). A locked letter scores. A miss drops progress. Not a ROM, not an emulator.

## Play

```
pip install -r requirements.txt
python3 kermesite_cipher.py --play
```

A/D or arrows move the seal. Space stamps. R restarts. Esc quits.

## Record a 9:16 reel

```
python3 kermesite_cipher.py --record
```

Headless autoplay writes a 1080x1920, 15s, 30fps H.264 MP4 (dummy SDL video driver).
